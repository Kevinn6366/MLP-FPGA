# 四层整数 MLP：从单神经元到张量推理

## 本轮范围

用户确认结构为 4→8→8→8→2：四个带权重的全连接层，前三层 ReLU，最后一层保留正负数。
只做推理，不训练；权重在电脑上生成一次并固定。当前交付 RTL 和行为仿真，没有综合、实现或上板。
随机权重只用于检验计算，输出不代表有意义的分类结果。

## 张量接口

一次请求输入形状 [1,4]，输出形状 [1,2]。第一维 1 表示一次处理一个样本。

| 接口 | 约定 |
| --- | --- |
| x_packed[31:0] | 四个有符号 8 位整数；x0 位于 [7:0]，x3 位于 [31:24] |
| y_packed[63:0] | 两个有符号 32 位整数；y0 位于 [31:0]，y1 位于 [63:32] |
| start | 空闲时置高一个时钟，提交请求 |
| busy | 为 1 表示处理中，期间 start 不接收、不排队 |
| done | 输出两个元素同时更新时置高一个时钟 |
| reset | 同步高有效复位，优先于 start，取消正在执行的请求 |

输入只在 IDLE 且 start=1 的上升沿锁存，随后外部输入可以变化。
输出在下一次完成前保持不变，复位会清零。若 start 一直保持高，回到空闲后会再接受一次请求，所以通常应发单周期脉冲。
端口总线本身是打包位串；解释各元素时必须按有符号数处理。对整个 64 位 y_packed 选择 Signed Decimal 不能正确显示两个独立元素。
本阶段没有 AXI、ARM 程序或板级引脚接口，testbench 直接驱动张量接口。

## 数值格式与范围证明

全部采用整数，小数位为 0。输入为 signed int8（-128～127），权重以 signed int8 保存，固定取 -3～3；偏置以 signed int16 保存，固定取 -8～8。
层间数据与输出为 signed int32，乘积与累加器为 signed 40 位。

用 B0=128 表示输入绝对值上界。每层有 N 个输入时，部分累加与最终结果都不超过 N×3×B+8：

| 层 | 输入数 | 输出数 | 绝对值保守上界 |
| --- | --- | --- | --- |
| 1 | 4 | 8 | 1544 |
| 2 | 8 | 8 | 37064 |
| 3 | 8 | 8 | 889544 |
| 4 | 8 | 2 | 21349064 |

所有上界小于 2^31，因此存回 32 位是精确的，没有丢失有效数值。本版本没有缩放、舍入和饱和操作。
范围证明覆盖全部合法输入，并不只是测试样本。改变权重范围、层宽或输入格式后必须重新证明，不能直接沿用截位代码。
Python 同时计算整数参考和浮点参考，本版整数在浮点精确整数范围内，二者应完全一致；这不是训练模型的量化精度评估。

## 随机权重在哪里

- model/mlp4_weights.json：固定种子 20261010 生成的 176 个权重、26 个偏置。
- rtl/mlp4_weights.vh：由同一份参数导出的 case ROM，按输出神经元逐行存放。
- model/mlp_reference.py：参考模型、范围检查和生成器。
- sim/mlp4_vectors.vh：93 组输入，以及每个神经元的预激活和激活后答案。

权重 W[o][i] 的行表示输出神经元 o，列表示输入元素 i。Python 按矩阵逐行求和；RTL 按 ROM 地址串行读取。
权重偏移依次是 0、32、96、160，偏置偏移依次是 0、8、16、24。
权重不会在每次推理时重随机，也没有在 FPGA 中加入随机数发生器。

## 数据如何逐层流动

电路中有两个各含 8 个 32 位元素的存储区 bank_a、bank_b。

```text
输入锁存到 A
第1层：A → 乘加/ReLU → B
第2层：B → 乘加/ReLU → A
第3层：A → 乘加/ReLU → B
第4层：B → 乘加      → A
把 A[0]、A[1] 同时送到 y_packed
```

读写分开，正在计算的输出不会覆盖本层仍需读取的输入。当前代码使用寄存器数组；是否映射为 BRAM、乘法用多少 DSP，必须以后查看综合报告，不能根据变量名推断。

与单神经元相比，新增三个调度维度：

| 寄存器 | 意义 |
| --- | --- |
| layer | 0～3，当前计算哪一层 |
| neuron | 当前层正在计算哪个输出神经元 |
| input_index | 该神经元当前处理哪个输入元素 |

## 状态机与时钟

```text
IDLE(0)：锁存输入
  ↓
INIT(1)：取当前偏置，清输入计数
  ↓
MAC(2)：每拍 acc += 输入×权重，重复 4 或 8 拍
  ↓
STORE(3)：ReLU/原值存入目标存储区
  ├─ 本层还有神经元 → INIT
  ├─ 还有下一层     → layer+1，INIT
  └─ 第4层完成      → FINISH(4)
FINISH：更新输出张量，done=1，返回 IDLE
```

非阻塞赋值仍然使用更新前的值。STORE 与最后一次 MAC 分开，让存储操作读到完整累加结果。
FINISH 与最后一次 STORE 分开，让两个输出元素都已存入 A 后再统一更新外部输出。

请求接受到 done 的延迟为：

```text
第1层：8×(1拍初始化+4拍乘加+1拍存储) = 48拍
第2层：8×(1+8+1) = 80拍
第3层：8×(1+8+1) = 80拍
第4层：2×(1+8+1) = 20拍
最后更新输出 = 1拍
共 229 个时钟周期
```

这是无流水重叠的串行结构，一次仅处理一个样本。仿真时钟周期 10ns，因此模拟接受到完成间隔 2290ns；真实板上频率和资源使用尚未验证。

## 第一组输入应看到什么

固定参数下，输入 [1,2,3,4]，各层结果：

```text
第1层：[14, 1, 0, 0, 0, 4, 16, 0]
第2层：[25, 0, 1, 0, 0, 0, 71, 0]
第3层：[0, 0, 192, 32, 0, 144, 0, 294]
第4层：[-59, -139]
```

第一组请求在 25ns 接受，各层最后一次存储分别在 505、1305、2105、2305ns；2315ns 更新输出并置 done=1。
在这些时刻稍右侧读更新后的值，避免混淆上升沿两边的数据。中间层完成后，下一层会逐渐覆盖另一个存储区，所以应在对应时刻读对应存储区。
