## 当前格式
- 输入 signed int8；权重 signed int8（-3～3）；偏置 signed int16（-8～8）。
- 层间/输出 signed int32，累加 signed 40 位，小数位 0，无缩放、舍入、饱和。
- 各层绝对值上界 1544、37064、889544、21349064，范围内精确。
- 前三层 ReLU，最后一层有符号输出；随机权重种子 20261010。
- 同步复位；忙碌时忽略请求；输出张量在 done 时原子更新。
